## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent `file_upload` event → `event_photo` row | Agent-supplied photo URL and the joined guest name cross into durable storage and onto a public-facing wall |
| `event_photo.photo_url` → room-screen `<img src>` | A stored URL is rendered by every TV browser |
| room-screen TV → `GET /display-screen`, `WS /display` | Existing Phase 5 boundary, now carrying event configuration and a guest's photo and name |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-08 | Information Disclosure | guest names in new photo-history log lines | high | mitigate | Every new log line goes through `labelLogger` and is a template string, so the winston masking formatters run on it; no object-form logging, per the `debugRawPayload()` warning in `logging/logger.ts` |
| T-08-09 | Information Disclosure | `DisplaySnapshot` widening | medium | mitigate | `justCaptured` is a two-key projection built from a purpose-built store method that returns only `{photoUrl, name, capturedAt}`; no raw `event_photo` row reaches the wire, preserving the D-15 shape guarantee stated on the type itself |
| T-08-10 | Tampering | stored photo URL rendered into `<img src>` | medium | mitigate | The URL originates from the Agent over the authenticated WS link, is stored verbatim, and is only ever placed in an image source — never fetched server-side and never interpolated into executable markup; a failed load falls back to the neutral placeholder tile |

| T-08-SC | Tampering | font binaries fetched from a third party | medium | mitigate | Files are downloaded once, committed to the repo, and served from this host; the rendered page carries no external stylesheet or font link, so a venue with no internet and a compromised CDN both fail closed.
