<objective>
Make the booth Agent configurable from the operator console instead of by walking to the booth PC
and editing `.env` — for exactly the four fields where that is safe, with the three bootstrap
credentials and the log directory structurally unreachable from the network, and with one step
back when a save turns out to be wrong mid-event.

Purpose: UI-02 is the last ROADMAP success criterion of this phase and the only one that spans
both repositories. It is also the one with a real trap: the dslrBooth client captures its port and
password once at construction, so a plan that ships only message plumbing would look complete and
change nothing.

Output: the `config_request` / `config` / `reload_config` message triple, a safe-field allow-list
enforced in code on both sides, live-mutable dslrBooth credentials on the Agent, and the CMS
Agent-configuration page with its one-step restore.
</objective>
