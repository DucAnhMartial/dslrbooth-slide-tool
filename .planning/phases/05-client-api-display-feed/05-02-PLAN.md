<objective>
Expand the proven `/status/:jobId` slice horizontally: make D-11's closed vocabulary
exhaustive and provably closed, collapse every `/status` miss into one indistinguishable
404, and implement D-05's suppression so an estimate is never promised while the booth
cannot serve.

Purpose: this is the customer-facing surface of every failure Phases 2, 3 and 4 built. An
unmapped internal state here is what leaves a real guest staring at a position number for a
job that will never run.

Output: an exhaustive table-driven vocabulary test, a hardened 404 family, and the
suppression branch — all asserted against the same real ephemeral store as 05-01.
</objective>
