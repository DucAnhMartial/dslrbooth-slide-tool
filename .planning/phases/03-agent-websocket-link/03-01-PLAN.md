<objective>
Replace the Agent's authentication handshake, end to end across both repositories, with a
header-only Bearer credential that is verified in constant time and rejected with HTTP 401
**before** the WebSocket handshake completes. This is the tracer slice for Phase 3: one path —
Agent client → HTTP upgrade → authenticated socket — wired through every layer that the
one-way contract change touches, proven by real `ws` clients against a real `AgentServer` on
an ephemeral port, and committed for keeps.

Purpose: today the credential travels in the URL query string, is compared with a plain `!==`,
and is checked only *after* `handleUpgrade()` has already completed the handshake — an
unauthenticated peer holds an open socket, briefly, before being closed with code 4001
(`mirror-request/src/agent/agentServer.ts:29-43`, read this session). D-05..D-09 close all three
gaps at once, and deliberately break compatibility: the query-string form is deleted, not
deprecated.

Output: a server that answers an unauthorized `/agent` upgrade with a bare 401 on the raw
socket; an Agent that sends `Authorization: Bearer <token>`; the Agent repository's first test
harness; a new server-side auth suite; and the one pre-existing test that the change breaks,
repaired rather than deleted.

**Why this is the tracer and not a prototype.** It is production code with production error
handling on the single path it wires. Nothing here is stubbed. The expansion plans (03-02 →
03-05) build outward from this proven spine: transport observability and liveness (03-02),
dispatch connectivity and the command payload (03-03), disconnect recovery and event coverage
(03-04), and the operator contract (03-05).
