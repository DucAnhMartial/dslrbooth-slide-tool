<objective>
**As a** booth operator, **I want to** start and configure the Agent from a window on the booth PC,
**so that** running a photo booth never depends on remembering a terminal command.
*(Phase story; this plan is the slice that makes the window real.)*

The Agent becomes an application: an Electron main process hosting the factory from plan 10-01, a
user-data JSON configuration store the window writes over IPC, and a renderer that shows the state
of the relay and can start and stop it. This is the thin slice through every layer the phase
touches — settings form to store to factory to socket — and after it the operator can configure and
run the Agent without a terminal.

Purpose: success criteria 1 and 2 in one path. Everything here is provable headless on this Linux
machine except the Chromium window itself, which has no display server to open on; that half is
listed honestly for the phase gate rather than pretended into a test.

Output: the Electron entry, preload and IPC surface, the configuration store with its
credential-safety contract, a plain HTML renderer with a settings form and a status panel, the
packaging wiring that lets the two build paths coexist, and three test files.
</objective>
