<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Live event snapshot to CSS selection | Stored or hand-edited values choose a browser-visible layout. |
| Photo URL to contain_blur decoration | A network-provided URL becomes a CSS background source in the standalone page. |
| Template/guest name to caption element | Untrusted text becomes visible wall-screen content. |
| Shared config contract to two display pages | A shared field could accidentally cause visual logic to drift into the waiting page. |

| T-999.1-08 | Tampering | slidesPage layout state | medium | mitigate | Exact normalized config tokens choose classes/attributes and invalid values fall back safely. |
