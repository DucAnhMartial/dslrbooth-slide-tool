<objective>
Finish the phase: give the two toggles an operator-facing control that actually writes them, make
the slides surface worth pointing a television at, write down how to use both, and put a human in
front of a real screen.

Purpose: plan 09-01 made the toggles true on the wire and on both screens, but an operator still
has to edit SQLite to change them — a capability nobody would call shipped. And a slides view that
merely deletes the sidebar is exactly what CONTEXT's UI-01 note forbids: the photo surface has to
reclaim the width, which is a design task, not a `display:none` on an element. The last task is the
one thing no test in this repository can settle — whether the result reads from where guests stand.

Output: two checkboxes and their server-side validator, the slides surface's design pass, a
cross-page invariant test that turns future drift into a red suite, OPS-RUNBOOK §13, and a blocking
human gate.
</objective>
